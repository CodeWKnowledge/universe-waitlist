# UniVerse Waitlist Application

This is the standalone waitlist landing page for the **UniVerse** university student marketplace platform.

## Features
- **Countdown Timer**: Target launch date countdown.
- **Priority Intake Form**: Safe validation and local ingestion of waitlist spots.
- **Referral Ticket Flow**: Interactive referral link generator & WhatsApp/X sharing.
- **FAQ Accordion**: Information on student verification, safety protocols, and fees.

## Tech Stack
- **Framework**: React + Vite
- **Styling**: TailwindCSS v4
- **Icons**: Hugeicons React

## Local Development
To run this application locally:

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server** (runs on port `5173`):
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
